# TaskFlow — 8D Animated To-Do List

Professional colorful productivity UI created for the Veda Technology Level 1 Day 16 task.

### Features
- Add, complete and delete tasks
- All / Active / Done filters
- Clear completed
- Live statistics
- Responsive mobile layout
- Animated gradient accents and 8D-style depth
- Array-based in-memory state
- Event delegation
- No persistence, matching the assignment requirement

### Tech
HTML5 • CSS3 • Vanilla JavaScript

### Run
Open `index.html` directly in a browser. No dependencies or build tools are required.
